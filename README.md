# Ethiopia Financial Inclusion Forecasting

Forecasting system for Ethiopia's digital financial transformation, built for Selam Analytics.
Predicts Access (Account Ownership) and Usage (Digital Payment Adoption) for 2025-2027.

## Setup
pip install -r requirements.txt

## Project Structure
See task branches: task-1 (data), task-2 (EDA), task-3 (impact modeling), task-4 (forecasting), task-5 (dashboard)
